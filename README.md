# 🗺️ Интерактивный справочник ОКТМО

Онлайн-справочник по Общероссийскому классификатору территорий муниципальных образований (ОК 033-2013). Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/oktmo/](https://prog815.github.io/oktmo/)

Этот справочник — для тех, кто сталкивается с указанием кодов муниципальных образований и населённых пунктов в налоговых декларациях, платёжных поручениях, статистической отчётности и при регистрации бизнеса. Главная задача — помочь быстро найти корректный код ОКТМО по названию или самому коду и скопировать его в один клик.

---

## Что кодирует ОКТМО

**ОКТМО** — общероссийский классификатор, в котором записаны **территории муниципальных образований и населённых пунктов**. Он отвечает на вопрос **«к какому муниципалитету относится объект»**.

В текущем снимке справочника содержится **172 075 записей**. Классификатор представлен плоским списком (без дерева в интерфейсе). Записи разделены на два типа:

- **МО** — муниципальные образования (8-значные коды, например `01512000`);
- **НП** — населённые пункты (11-значные коды, например `01512000101`).

Каждая карточка содержит:
- **Код** (8 или 11 цифр). Первые 2 цифры — код субъекта РФ.
- **Тип** (МО или НП).
- **Субъект РФ** (регион, к которому относится объект).
- **Наименование** (например, «с Залесово»).
- **Дата введения** (дата вступления кода в действие).
- **КЧ** (контрольное число — служебный знак, в сам код не входит).

> **Важно про ОКАТО.** ОКТМО пришёл на замену ОКАТО для целей налогообложения и бюджетных платежей с 2014 года. Если в форме есть поле «ОКТМО» — используйте этот справочник. Коды ОКТМО и ОКАТО не взаимозаменяемы.

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по коду.** Введите `01512000` или `01 512` (с пробелами, точками или без). Поиск строго с начала кода.
- **Поиск по названию.** Одно или несколько слов в любом порядке по логике «И»: `Залесово`, `Змеиногорский район`.
- **Смешанный запрос.** Введите `01 Залесово` — найдёт все объекты, где код начинается с `01` **и** в названии есть «Залесово».
- **Копирование в один клик.** Клик по коду копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Фильтры.** Выпадающие списки для выбора типа объекта (МО / НП) и субъекта РФ. Бейджи в карточке тоже кликабельные.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере. В текст автоматически подставляются наименование, ссылка, код, субъект и дата введения.
- **Прямые ссылки на коды.** Каждый код можно передать через `?code=…` в адресе.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## Как пользоваться

1. **Откройте страницу** — сразу показывается первая порция записей в порядке кодов.
2. **Начните вводить запрос** — код или слово из названия.
3. **Кликните по коду** в карточке — он скопируется.
4. **Нажмите `📤 Поделиться`**, чтобы отправить карточку коллеге.
5. **Выберите тип объекта или субъект РФ** в выпадающих списках, чтобы отфильтровать список.
6. **Нажмите «Очистить»**, чтобы сбросить запрос и фильтры.

## Примеры запросов

- `01 512 000` или `01512000` — Залесовский муниципальный округ (МО).
- `01 512 000 101` — село Залесово внутри округа (НП).
- `Москва` — все муниципальные образования и населённые пункты с этим словом.
- `45` — коды, начинающиеся с `45` (Москва и её муниципалитеты).
- `Алтайский край` + фильтр «МО» — все муниципальные образования Алтайского края.

**Популярные коды:**
- `45 000 000` — город Москва (МО);
- `40 000 000` — город Санкт-Петербург (МО);
- `67 000 000` — город Севастополь (МО);
- `01 512 000` — Залесовский муниципальный округ (Алтайский край);
- `01 512 000 101` — село Залесово (внутри Залесовского МО).
